# Personal Portfolio Website

A responsive personal portfolio website showcasing my projects, technical skills, and professional profile.

## Overview

I like it my way minimalistic and to the point

## Features

- Responsive single-page portfolio design
- Featured project showcase with technical highlights
- Technology stack section with visual skill representation
- GitHub Pages deployment for live hosting
- Minimal and professional UI focused on readability
- Smart MCQ Solver and EverTrek reports with section navigation, reading-size controls, expandable details, and printable layouts
- Interactive MCQ metric comparisons and on-demand EverTrek recordings
- Shared light/dark theme with text-only controls

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript (no build step)

## Project reports

- [Smart MCQ Solver](smart-mcq-solver.html): original report figures, grouped validation results, updated competition placement, and live Gradio application link.
- [EverTrek](evertrek.html): architecture, database schema, role workflows, six recordings, and API examples.
- [Chest X-ray Imaging](report.html): existing technical report.

The original PDFs and recordings remain in `Docs/`. Lightweight demo posters and extracted MCQ figures live in `assets/reports/`. Recordings load only after selecting **Play demo**; **Stop demo** returns to the still preview. The supplied recordings preserve the original application's appearance.

Open `index.html` directly, or serve this directory with `python -m http.server 5173`. Deploy the static files together, including `Docs/` and `assets/`, so report links and media resolve correctly. No package installation or build is required.
